- 세부 설계 내용은 이 문서에 직접 적지 않고, 별도의 문서에 적는다. (MEMORY.md 방식)
- 세부 설계 내용 문서를 추가하는 방법 :
	1. [설계 문서 양식](DESIGN/001_설계_문서_양식.md) 문서를 주제에 맞는 이름으로 DESIGN 디렉토리에 복사하여 만든다.
	2. 양식에 제시된 지침에 따라 다음과 같은 내용을 작성한다. (작성된 문서를 수정할 때도 아래 내용을 따른다.)
		- REQUIREMENTS : 사용자가 제기한 요청 사항
		- SPECIFICATIONS : 사용자 요청 사항에서 파생된 세부적인 개발 규격
		- IMPLEMENT : 구현 방법, 분량이 많을 경우 세부 장절(## 이하)을 추가할 수 있다.
		- RATIONALE : 기술적 검토 내용 및 결정 이유, 코딩과정에서 필요한 정보만 적어 둔다.
	3. 목록에 등록되어 있는 기존 형식 대로 새 문서를 추가 등록한다.
