# 업무 개요

- 템플릿을 복사해 새 프로젝트를 시작할 때 처음 한 번 해야 할 일이다. 템플릿 상태의 문서들을 프로젝트 목적에 부합하도록 수정한다.
- 진행 방식: 1번을 한 뒤 세션을 다시 시작하지 않고 이어서 간다. 사용자에게는 2번에서 결정 사항을 한 번에 묻고, 3번부터 9번까지는 질문 없이 끝까지 처리한다.
- 이 세션에서는 메모리를 저장하지 않는다. (1번에서 고친 설정은 다음 세션부터 적용된다. 이 세션에서 저장하면 템플릿 폴더에 쌓인다.)
- 9번 완료 처리는 "마무리" 요청을 기다리지 않고 바로 한다. (프로젝트 `CLAUDE.md`의 "문서의 작성 및 갱신 규칙" 3번은 이 완료 처리에 적용하지 않는다.)

# 세부 업무 목록

- [ ] **1. `autoMemoryDirectory` 고치기 :**
	- `.claude\settings.json`의 `autoMemoryDirectory`는 템플릿의 `Documents\MEMORY`를 가리킨다. 이 프로젝트의 `Documents\MEMORY` 절대 경로로 바꾼다. 경로의 `\`는 JSON에서 `\\`로 쓴다.
	- `CLAUDE.md` 맨 위의 "초기 설정 전" 장절을 통째로 지운다.
- [ ] **2. 결정 사항을 한 번에 묻기 :**
	- 다음 네 가지를 한 번에 묻는다.
		- 프로젝트 목적
		- 이름 (답이 없으면 폴더 이름을 쓴다.)
		- 개발 언어와 IDE (정해지지 않았으면 정해지지 않았다고 적고, 임의로 고르지 않는다.)
		- 실행파일의 git 추적 여부
- [ ] **3. 프로젝트 이름 반영 :**
	- `CLAUDE.md`의 `# 프로젝트 개요`에 있는 "이름 : (작성 예정)"을 정해진 이름으로 바꾼다.
- [ ] **4. `Source\Build\` 정리 :**
	- 개발 환경에 컴파일·링크 단계나 IDE 프로젝트 파일이 없으면(예: Python) 이 폴더를 삭제하고 `CLAUDE.md`의 `Source\Build\` 관련 내용을 지운다. 필요하면 그대로 둔다.
- [ ] **5. `Source\파일정리.bat` 수정 :**
	- 0바이트인 이 파일을, 해당 언어와 IDE가 컴파일·링크 과정에서 만드는 중간 산출물만 지우도록 수정한다. 소스, 프로젝트 파일, 설정, 실행파일은 지우지 않는다.
	- CP949(BOM 없음)+CRLF이므로 `cp949-crlf-edit` 스킬 방식으로 수정한다.
	- 지울 중간 산출물이 없으면 수정하지 않고, 마지막 보고에 그 이유를 쓴다.
- [ ] **6. `.gitignore` 재작성 :**
	- 쓰지 않는 환경의 패턴은 지우고, 이 프로젝트의 중간 산출물 패턴만 남기거나 새로 쓴다. 5번과 어긋나지 않게 한다.
	- 프로젝트 공통 항목(Claude Code, Obsidian, `/Temp/*`, `/Reference/` 등)은 유지한다.
	- 실행파일 추적 여부는 2번의 답에 따른다.
- [ ] **7. `CLAUDE.md`의 "작성 예정" 항목 채우기 :**
	- "목표", "용어 정의", "규칙"을 지금 알 수 있는 것만 쓴다. 정해지지 않은 사항은 정해지지 않았다고 쓴다.
- [ ] **8. 옵시디언 볼트 등록 안내 :**
	- `Documents\`는 옵시디언 볼트(`Documents\.obsidian`)이다. 사용자에게 등록 방법만 알리고 끝낸다. 등록 여부는 확인하거나 기다리지 않는다.
	- 방법: 옵시디언에서 "폴더를 볼트로 열기"(Open folder as vault)를 선택하고 이 프로젝트의 `Documents\`를 고른다.
	- 등록하지 않으면 사용자가 AI 전용 기록 문서를 옵시디언으로 열어 볼 수 없다.
- [ ] **9. 완료 처리 (문서 정리까지만) :**
	- `PROGRESS.md`의 "현재 진행 중인 업무"에 있는 이 문서의 줄을 "완료된 업무"로 옮기고 `[x]`로 표시한다.
	- 이 문서 맨 위에 "완료됨"을 표시하고, 정한 프로젝트 이름과 목적, 바꾼 설정, 채운 항목을 간단히 적는다. (문서는 삭제하지 않고 보존한다.)
	- 문서를 수정했으므로 진척상황 보고를 수행한다.
	- `Temp\` 정리와 CBM 색인 갱신은 하지 않는다.
