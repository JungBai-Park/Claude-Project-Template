# 업무 개요

* 이 업무 단위가 무엇을 달성하려는 것인지 한두 문장으로 적는다.

# 세부 업무 목록

* 체크박스 항목으로 적는다. 항목 이름 뒤에 `:`를 붙이고, 설명은 다음 줄부터 들여쓴 목록으로 적는다.
  설명이 필요 없는 항목은 이름만 적는다.
* 완료 표시(`[x]`)는 "마무리" 때 일괄로 반영한다.
* 한 항목은 한 세션 안에 끝낼 수 있는 크기로 적는다.
* 진행하면서 항목을 추가/삭제할 수 있다. 취소된 항목은 남기지 않고 지운다.

- [ ] **세부 업무 1 :**
	- 설명
	- 설명
- [ ] **세부 업무 2 :**
	- 설명

# 현재 상태 및 다음 단계

* 어디까지 진행되었고, 다음 세션이 이어서 무엇부터 해야 하는지 적는다.
* 현재 세션의 문맥을 모르는 다음 세션이 바로 이어갈 수 있을 정도로 적는다.

# 미결 사항 (Issue)

* 사용자와 협의가 필요한 내용이 있을 때만 적는다. 없으면 "없음"이라고 적는다.
* 각 사항마다 다음 세 가지를 모두 적는다.
	* 발생 조건 : 어떤 경우(입력, 사용 상황, 문서 형태)에 발생하는가?
	* 문제점 : 발생하면 무엇이 왜 문제인가?
	* 용어 설명 : 질문에 쓰인 용어 중 사용자가 모를 수 있는 것
* 결정이 나면 "마무리" 명령에서 이 항목을 지우고 결정 내용을 적절한 문서(DESIGN 또는 PROGRESS)에 반영한다.

# 관련 문서

* 이 업무와 관련된 DESIGN, PITFALLS 문서와 소스 경로를 링크나 경로로 적는다.
