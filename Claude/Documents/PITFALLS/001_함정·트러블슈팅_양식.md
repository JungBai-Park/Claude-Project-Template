
# 문제 상황 (What Happened)

* 상태 : 해결/미해결/임시조치 중 하나의 상태를 갖는다.
* 언제, 어떤 작업을 하다가 문제가 발생했는지 설명한다.
* 현상, 에러 메시지, 또는 잘못 접근했던 방식을 작성한다.

# 원인 분석 (Root Cause)

* 왜 이 문제가 발생했는지 근본적인 원인을 기술한다.
* 기술적 제약 사항이나 오해했던 부분을 명시한다.

# 해결 방법 및 올바른 접근법 (Solution)

* 문제를 어떻게 해결했는지 구체적인 방법을 작성한다.
* 필요시 올바른 코드 스니펫이나 설정 방법을 첨부한다.
